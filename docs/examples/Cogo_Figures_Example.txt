// COGO FIGURES EXAMPLE - CURVES & REVERSE CURVES
// This script thoroughly tests the creation of figures with regular and reverse horizontal curves using the XC command structure.

CLEAR

// 1. ESTABLISH BASE PARCEL CONTROL
NE 1 5000.0000 5000.0000 "SW Corner"
NE 2 5200.0000 5000.0000 "SE Corner"
NE 3 5200.0000 5300.0000 "NE Corner"
NE 4 5000.0000 5300.0000 "NW Corner"

// 2. CREATE A TRACT WITH CURVES
// We will build a boundary that contains synthetic horizontal curves to represent a winding road frontage.
BEG TRACT_CURVES_1
CONT 1
CONT 2
// At point 2, we leave the linear segment and begin a curve.
// Format: XC ZD (BULB) [radius] [chord-azimuth] [chord-distance]
// A standard forward curve
XC ZD (BULB) 100.0 45.0000 75.0
// A reverse curve flipping back into the tract
XC ZD (BULB) 150.0 315.0000 80.0
// Another forward curve continuing the road path
XC ZD (BULB) 100.0 45.0000 90.0

CONT 4
CONT 1
END

// Validate the closure of the newly formed curvilinear boundary
MAPCHECK TRACT_CURVES_1

// 3. RKRK INTERSECTIONS & CURVES
// We can also synthesize curves that branch from complex intersections.
RKRK 1 300.0 2 300.0
SAVE NORTH 100
RKRK 3 300.0 4 300.0
SAVE NORTH 101

BEG TRACT_REVERSE
CONT 100
// Extending reverse curves along computed points
XC ZD (BULB) 200.0 90.0000 150.0
XC ZD (BULB) 200.0 270.0000 150.0
CONT 101
CONT 100
END

MAPCHECK TRACT_REVERSE
