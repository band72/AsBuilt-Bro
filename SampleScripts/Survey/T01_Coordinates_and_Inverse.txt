// ============================================================
//  TUTORIAL 01 — COORDINATE ENTRY & INVERSE
//  Topic: How to store survey control points by coordinate,
//         and then calculate distances and bearings between them.
//
//  Commands used: CLEAR, PT, NE, NEZ, INV, AZ, LIST
// ============================================================

CLEAR

// ----------------------------------------------------------
// SECTION 1: Entering Points by Northing / Easting / Elevation
// ----------------------------------------------------------
// The PT command stores a point with a full coordinate.
// Syntax: PT <PointID> <Northing> <Easting> <Elevation> <Description>

PT 1  10000.00  10000.00  100.00  CONTROL
PT 2  10000.00  10500.00  100.00  CONTROL
PT 3  10500.00  10500.00  100.25  CONTROL
PT 4  10500.00  10000.00  100.15  CONTROL

// PT creates the anchor "monument" points at survey control.
// Think of these as the corner pins or benchmarks of your project.

// ----------------------------------------------------------
// SECTION 2: NEZ Shorthand (Northing Easting only, no description)
// ----------------------------------------------------------
// NEZ is identical to PT but description is omitted.

NEZ 10  10200.00  10200.00  99.50
NEZ 11  10300.00  10200.00  99.45
NEZ 12  10300.00  10300.00  99.40
NEZ 13  10200.00  10300.00  99.35

// These interior points might represent a drainage feature
// or simply additional topo shots inside the control quad.

// ----------------------------------------------------------
// SECTION 3: Inverse — Calculate Bearing & Distance
// ----------------------------------------------------------
// INV computes the direction (bearing) and distance FROM point A TO point B.
// Syntax: INV <FromPoint> <ToPoint>

INV 1 2
// Result: Due East — Bearing S 90° E, Distance = 500.00 ft

INV 2 3
// Result: Due North — Bearing N 0° E, Distance = 500.00 ft

INV 3 4
// Result: Due West — Bearing S 90° W, Distance = 500.00 ft

INV 4 1
// Result: Due South — Bearing S 0° E, Distance = 500.00 ft

// ----------------------------------------------------------
// SECTION 4: Azimuth — Display as 360-degree azimuth
// ----------------------------------------------------------
// AZ is like INV but reports as full circle azimuth (0-360°).

AZ 1 2
AZ 2 3
AZ 10 12

// ----------------------------------------------------------
// SECTION 5: Figure — Connect the Control Quad
// ----------------------------------------------------------
// BEG...CONT...CLOSE...END draws a boundary figure using the stored points.

BEG CONTROL_QUAD
CONT 1
CONT 2
CONT 3
CONT 4
CLOSE
END

// Now check closure and compute area:
MAPCHK CONTROL_QUAD
// Expected: 500 x 500 = 250,000 sq ft = 5.739 acres
// Closure error = 0.0000 (perfect — we entered exact coordinates)

BEG INTERIOR_BOX
CONT 10
CONT 11
CONT 12
CONT 13
CLOSE
END

MAPCHK INTERIOR_BOX
// Expected: 100 x 100 = 10,000 sq ft = 0.2296 acres

// ----------------------------------------------------------
// SECTION 6: LIST — Display all stored points
// ----------------------------------------------------------
LIST POINTS

// ============================================================
//  END OF TUTORIAL 01
//  Key takeaways:
//  - PT/NEZ store coordinates in memory
//  - INV gives bearing and distance between any two points
//  - AZ gives 360° azimuth
//  - MAPCHK verifies closure and computes area
// ============================================================
