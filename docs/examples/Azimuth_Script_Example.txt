// COGO SCRIPT EXAMPLE - ROBUST TEST OF ALL COGO FEATURES
// This script demonstrates the creation of control points, calculation of new points,
// intersections, traversing, and figure creation to test boundary mechanics.

CLEAR

// 1. ESTABLISH CONTROL POINTS
NEZ 1 5000.000 5000.000 100.0 "START"
NEZ 2 6000.000 5000.000 100.0 "REF/BACKSIGHT"

// 2. SET STATION AND BACKSIGHT
STN 1
BS 2

// 3. BEARINGS AND DISTANCES (BD)
// Calculate new points using bearing and distance from known points
BD 3 1 45.0000 500.0 "PT 3"
BD 4 2 135.0000 500.0 "PT 4"

// 4. INTERSECTIONS
// Azimuth-Azimuth Intersection
AZAZ 5 3 180.0000 4 270.0000 "INT AZAZ"
// Bearing-Bearing Intersection
BB 6 3 1 45.0000 4 2 135.0000 "INT BB"
// Line-Line Offset Intersection
LNLN 7 1 2 50.0 3 4 0.0 "OFFSET INT"

// 5. TRAVERSE (TR)
TR 8 7 90.0000 100.0 "TRAVERSE PT1"
TR 9 8 180.0000 100.0 "TRAVERSE PT2"

// 6. CALCULATIONS AND METADATA INFO
// Get the Azimuth from 1 to 5
AZ 1 5
// Get the Distance from 1 to 5
DIST 1 5
// Calculate the Angle
ANG 2 1 3

// 7. FIGURES AND MAPCHECK
// Create a bounding lot figure out of calculated points
BEG LOT_1
CONT 1
CONT 2
CONT 4
CONT 3
CONT 1
END

// Validate the closure of the boundary
MAPCHECK LOT_1

// Show documentation
HELP
