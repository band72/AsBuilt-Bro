// ANGLE SCRIPT EXAMPLE - TRAVERSE AND SIDE SHOTS
// This script demonstrates using the Angle Distance (AD) command
// in conjunction with the Traverse Mode (TRAV ON / TRAV OFF).

CLEAR

// 1. ESTABLISH BASE CONTROL
NE 1 5000.0000 5000.0000 "Start Point"
NE 2 4000.0000 5000.0000 "Initial Backsight (South)"

STN 1
BS 2

// 2. ACTIVATE TRAVERSE MODE
// TRAV ON will automatically move your Station to the newly created point
// and automatically set your Backsight to your previous Station.
TRAV ON

// Turn angle 180 degrees right (Now facing North), walk 500 ft forward
AD 100 180.0000 500.0 "Traverse Point 1"

// 3. SHOOT SIDE SHOTS
// We want to shoot side points (trees, corners) without advancing our traverse station.
// We turn off Traverse Mode to keep our Station fixed entirely on Point 100, Backsight on 1.
TRAV OFF

// Now these are just radial side shots holding the Station steady
AD 101 45.0000 150.0 "Side Shot - Tree"
AD 102 315.0000 200.0 "Side Shot - Light Pole"

// 4. CONTINUE TRAVERSE
// Now we resume walking the property line.
TRAV ON

// Turn 90 degrees right from the backsight (Now facing East)
AD 200 90.0000 500.0 "Traverse Point 2"

// Turn 90 degrees right from the backsight (Now facing South)
AD 300 90.0000 500.0 "Traverse Point 3"

// Turn 90 degrees right from the backsight (Now facing West back to Start)
AD 400 90.0000 500.0 "Traverse Return"

// 5. DISABLE TRAVERSE MODE
TRAV OFF

// 6. VALIDATE LOOP
// We mathematically formed a perfect 500x500 survey box (1 -> 100 -> 200 -> 300 -> 400 -> 1)
BEG TRACT_ANGLE
CONT 1
CONT 100
CONT 200
CONT 300
CONT 400
CONT 1
END

MAPCHK TRACT_ANGLE
